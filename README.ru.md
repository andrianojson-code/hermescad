# HermesCAD + Hermes3D

[English](README.md) · **Русский**

[Hermes Agent](https://github.com/NousResearch/hermes-agent) превращает картинки в 3D-модели прямо на твоём ПК. Проект состоит из двух частей.

**HermesCAD**
- **На входе:** чертёж, скриншот или фото механической детали.
- **Работает в:** FreeCAD 1.0+.
- **На выходе:** **параметрическое** тело PartDesign с таблицей параметров «Params», которую можно править. Экспорт в STL, STEP, IGES, BREP.

**Hermes3D**
- **На входе:** скриншот или фото объекта свободной формы: игрушки, машинки, фигурки, ручки.
- **Работает в:** Blender 4.2+.
- **На выходе:** сетка из облачной нейросети image→3D, подогнанная под реальный размер и подготовленная к печати. Экспорт в STL, GLB, OBJ, FBX, PLY.

С Hermes общаешься обычным текстом, например: «вот чертёж, ширина 120, дай STL». Hermes вызывает MCP-инструменты этого репозитория и работает по skill с инструкциями.

## Установка (Windows)

Понадобятся:
- Python 3.10+ с python.org, при установке поставь галочку «Add to PATH»;
- Hermes Agent;
- FreeCAD 1.0+ и/или Blender 4.2+.

```bat
git clone https://github.com/andrianojson-code/hermescad.git
cd hermescad
install.bat
```

Установщик делает четыре вещи:
1. Подключает аддон во FreeCAD через junction, поэтому `git pull` сразу обновляет аддон. Заодно включает автозапуск моста.
2. Создаёт `.venv` и ставит туда оба MCP-сервера.
3. Копирует аддон в Blender и включает его. Ключ `-NoBlender` пропускает этот шаг.
4. Копирует skills в Hermes и выводит блок `mcp_servers` для `config.yaml`. Этот блок он также сохраняет в `hermes/config-snippet.generated.yaml`.

После установки:
1. Вставь этот блок в `config.yaml` Hermes. У десктопной версии файл лежит в `%LOCALAPPDATA%\hermes\`, у CLI — в `%USERPROFILE%\.hermes\`.
2. Перезапусти FreeCAD и/или Blender. Мосты запустятся сами.
3. В Hermes открой **новый** чат и попроси «проверь freecad_status» или «проверь blender_status».

Если аддон в Blender не включился, открой Edit → Preferences → Add-ons, найди «Hermes3D» и поставь галочку.

## Примеры запросов

- «Вот чертёж `plate.png`, ширина 120. Построй пластину толщиной 4 мм и дай STL.»
- «Сделай отверстия 8 мм и скругли углы R5.» / «Отмени последнее.»
- «Сделай 3D-модель этой игрушки в Blender, высота 60 мм, STL для печати.»
- «Импортируй `model.glb`, сделанную на tripo3d.ai, высота 40 мм, подготовь к печати.»

## Что важно знать

- **По чертежам** получается точная модель, **по фото** — приблизительная. Всегда называй Hermes хотя бы один реальный размер.
- Hermes3D обходится без видеокарты. Генерация идёт в бесплатном Space на Hugging Face с дневной квотой: её поднимает бесплатный токен в `HF_TOKEN`. Можно подключить и платный Tripo API.
- Нейросеть додумывает невидимую сторону объекта. В бесплатном варианте модель получается без текстуры.

**Безопасность.** Мосты слушают только `127.0.0.1` и отклоняют запросы из браузера. Токен поддерживается и обязателен, если мост открыт в сеть. Выполнение произвольного Python отключается в настройках аддонов.
